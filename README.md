## 🌟 Основные возможности

### 1. Расчёт налогов ИП
- **Единый налог (Приложение 24 к НК РБ):**
  - Полная база актуальных ставок по всем городам Беларуси (Минск, Брест, Витебск, Гомель, Гродно, Могилёв, Бобруйск, Барановичи, Пинск, Борисов и др.).
  - Учёт льгот 20% (пенсионеры, инвалиды, многодетные) и 100%.
  - Автоматический контроль 40-кратного размера валовой выручки и расчёт доплаты 6%.
  - Генерация готового текста налоговой декларации для подачи в ИМНС.
- **Общая система налогообложения (ОСН 20%):**
  - Расчёт подоходного налога 20% с чистой прибыли.
  - Выбор способа признания расходов: фиксированный норматив 20% без подтверждающих документов (п. 36 ст. 205 НК) либо по фактическим документальным затратам.
  - Стандартные налоговые вычеты (ст. 209 НК) на самого плательщика и детей.
  - Контроль предельного годового порога 500 000 руб. (ставка 30% с суммы превышения).
  - Формирование текста квартальной декларации по подоходному налогу.

### 2. Взносы в ФСЗН и Белгосстрах
- Взносы ИП за себя: 35% от минимальной заработной платы с учётом фактических периодов деятельности.
- Взносы за наёмных работников: ФСЗН 34% (работодатель), пенсионный сбор 1% (работник), подоходный налог 13%, страхование от несчастных случаев в Белгосстрах 0,6%.
- Контроль сроков уплаты и формирования отчётов.

### 3. Кадровый учёт и печать документов
- Расчёт заработной платы до 3 наёмных сотрудников (согласно законодательству для ИП).
- Расчётно-платёжная ведомость с вычислением сумм к выплате «на руки».
- Табель учёта рабочего времени с разбивкой по дням и часам.
- Подготовка форм ПУ-1, ПУ-2, ПУ-3 и отчёта 4-фонд.
- Форматированная печать ведомостей и табелей на листах формата А4 в один клик.

### 4. Динамическая синхронизация нормативов
- Автоматическое обновление ставок законодательства (МЗП, базовая величина, вычеты, ставка рефинансирования НБРБ) через защищённый сервер.
- Автономный оффлайн-режим: при отсутствии интернета программа работает на сохранённых локальных данных.

### 5. Современный интерфейс
- Полная поддержка светлой и комфортной тёмной темы в стиле Claude Desktop.
- Интерактивный налоговый календарь с напоминанием ключевых сроков.
- Встроенные памятки по кассовым аппаратам, Книге замечаний и предложений и ответственности за нарушения.

## 🛡️ Предупреждение Windows SmartScreen при первом запуске

При первом запуске скачанного файла Windows может показать синий экран с надписью **«Система Windows защитила ваш компьютер»**. Это стандартное поведение фильтра SmartScreen для любого нового приложения, которое ещё не накопило репутацию в системе Microsoft.

**Почему это происходит?**

SmartScreen срабатывает на **все** новые программы от независимых разработчиков, которые ещё не приобрели платный сертификат подписи кода (Code Signing Certificate). Это не означает, что файл опасен — Windows просто предупреждает, что приложение загружено из интернета и не имеет цифровой подписи крупного издателя. Предупреждение появляется только один раз при первом запуске.

**Как запустить приложение:**

1. На синем экране SmartScreen нажмите ссылку **«Подробнее»** (она находится под текстом предупреждения).
2. Внизу экрана появится кнопка **«Выполнить в любом случае»** — нажмите её.
3. Приложение запустится. При последующих запусках предупреждение больше не появится.
